# v1b：程式端補對照＋查無資料先自我檢查（不改 prompt）

父候選：v0

## 改了什麼
- `LINKER_V2=1`：活動名稱 → campaign_id；版本附上線日；「到 N 月底」→ 結束日；沒提日期 → 明確提示「查全期間、不要加日期條件」
- `EMPTY_RETRY=1`：查無資料時，先請模型檢查 JOIN 和條件一次，SQL 有改才重跑

## 為什麼（v0 調整組錯題）
- 「健身挑戰短影音花了多少錢」：活動名稱沒有對照，模型反問 short_code；追問題「那它的點擊率呢」跟著錯（自己編了短網址）
- 「3.5.0 版上線當天到 8 月底」：對照只給了「8 月」，沒有上線日，模型只查 8 月
- 沒提日期的題目，模型自己加日期（同 v1a，這裡改用程式提示）
- 「東南亞每日平均 DAU」：JOIN 寫錯 → 查無資料 → 直接回「沒資料」
